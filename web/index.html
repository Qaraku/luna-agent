                            当前范围
                            
      
                            这些设置控制模型工具，不关闭模型服务连接，也不停止 Luna 保存会话。文件工具仍受项目范围约束；写入工具需要读取旧内容以生成差异。目录的自动写入范围可在工作区设置中查看，其他项目路径需要单次批准。
                            
      
      
                            高级：Full access
      
                            受限命令默认只读且离线；显式请求并获批后，可写入指定目录并通过代理访问公共 HTTP(S) 地址。宿主、私网地址和直接网络连接仍不可用。Full access 不使用文件或网络沙箱，命令可用当前系统用户的权限访问工作区外文件、读取凭据、修改或删除文件、联网，甚至影响 Luna 自身；它不会自动获得 root 权限。
                            
      
                            授权只对当前会话、当前服务进程生效，服务重启后必须重新确认。命令仍有超时和输出上限；Full access 程序可能故意脱离进程组，不能保证沙箱式的后代清理。
                            
      
                            权限模式不会自动启用工具；需要的命令能力仍由能力开关决定。
